# 🐱 小猫怎么了（Cat Mood）

一个判断猫咪情绪、并生成治愈系拟人插画的 **豆包 Skill**。

用户上传猫的照片 / 视频，它会：

1. 判断猫当前的情绪状态（放松 / 开心、紧张 / 害怕、生气 / 不爽、难过 / 不舒服）
2. 用拟人化的治愈口吻向主人解释
3. 以统一画风生成一张**与原图同比例、独立成图**的治愈系插画

核心理念：**可爱拟人为主、真实信号为辅、提供情绪价值**。适合猫主人随手一拍，发给 AI 问一句「我家猫怎么了」。



***

## ✨ 功能



| 能力     | 说明                           |
| ------ | ---------------------------- |
| 情绪识别   | 综合耳朵、尾巴、眼睛、姿态、声音、行为等信号判断四档情绪 |
| 拟人文案   | 以猫的第一人称向主人说话，附信号依据           |
| 印章插画   | 橡胶印章/复古版画风，与原图同比例、独立成图       |
| 方向处理   | 自动处理 HEIC/HEIF 方向，正确识别竖屏/横屏     |
| 就医提醒   | 检测到危险 / 健康信号时优先提示就医          |

## 🚀 安装（在豆包里使用）

### 方式一：对话安装（最简单，推荐）

复制下面这句话，发给豆包对话即可：

```
通过github安装 https://github.com/feihongly/cat-mood
```

豆包会自动拉取并安装「小猫怎么了」技能。

### 方式二：手动上传技能

1. 打开豆包客户端，点击左侧 **插件·技能·伙伴** → 切换到「技能」页 → 右上角 **+ 添加** → **上传技能**。
2. 把本仓库的 `skill` 文件夹（即 `cat-mood` 文件夹，内含 `SKILL.md`）拖入即可。
3. 完成后可在「我安装的」里查看，直接在对话中调用。

## 📸 使用示例

> **用户**
>
> ：
>
> 帮我看看我家猫怎么了
>
> ？[上传照片]
> **小猫怎么了**：
> 🐱 当前状态：放松 / 慵懒（前爪自然搭着、身体舒展、眼神平静）
> 主人，我现在很舒服哦～趴在这啥都不用想，等你来摸摸头啦。🐾
> （随后返回一张与原图同比例的印章风插画）

## 🎨 画风

默认使用**橡胶印章 / 复古版画风**（黑白手工印章，可选低饱和淡彩配色）；也支持**清新治愈水彩手绘风**、**吉卜力治愈动画风**等备选画风（见 `illustration-guide.md`）。插画默认**独立成图、与原图同比例**，不拼接成长图。
