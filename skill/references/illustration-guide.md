# 插画与成片制作参考

## 产品输出约定：分步交付，成片为「原图 + 印章插画」拼接

用户上传猫图后，**按三步分步交付**，最终输出一张「实拍原图 + 印章插画」拼接成的完整成片（3:4 或 4:3）：

1. **分析情绪 + 拟人文案**（见 `emotion-guide.md`，输出文字判断）
2. **生成一张印章风插画**（基于原图同比例、小章留白，独立成图）
3. **将原图与印章插画拼接成一张完整成片**（默认必做，方向由原图纵横比智能决定，见文末「拼接成片」）

> **拼接是默认输出，不是可选。** 每次生成都要把原图与印章插画拼成 3:4 或 4:3 的成片交付给用户；除非用户明确要求只出单张插画。

## 默认画风：橡胶印章 / 复古版画风

- 黑白手工印章 / 复古版画质感
- 边缘压印不均、油墨轻微渗化、纸张纤维可见
- 做旧纪念章、邮戳、版画元素点缀
- 整体克制精致，有复古旅行纪念感

### 可选配色：低饱和淡彩（默认倾向）

- 基础为黑白，可选用**低饱和淡彩**（约 8–16 色）：米白、浅橙、浅棕、浅灰绿、淡蓝等克制配色
- 配色须低饱和、不刺眼，保持复古做旧质感

### 比例与构图（默认「小章留白」方向）
- **插画比例 = 用户上传原图的比例**（先实测原图宽高比，再按同比例生成）
- **印章小且精致，四周留白充足**：猫咪印章主体（含短句与日期）整体作为一枚「盖在纸上的小章」，居中偏下，约占画布 30%–40%，四周留出大量空白，像盖在纸上的真实纪念章
- 文字少量、清晰，置于留白处，不遮挡猫咪主体

### 文字规范（关键）
- **主标题：中文拟人短句**，20 字以内，来自情绪拟人文案（见 `emotion-guide.md` 口吻）
- **日期：英文欧式风格**，如 `OCT 19, 2026`（如需精确时间可加时分），比中文日期更洋气
- **文字分两层排布**：上方中文拟人短句（主标题），下方英文日期；两者置于留白处，不遮挡猫咪主体
- 文字要清晰可读；**严禁**出现多余乱码字、重复短句、残留邮戳编号（如底部莫名数字/模糊字）
- 生成后必须核验画面文字，出现乱码需重新生成或清理

### 拟人短句风格库（agent 根据情绪与氛围自行选择）
| 情绪 | 氛围倾向 | 文案示例 |
|---|---|---|
| 放松/开心 | 天气好→慵懒治愈 | 「趴着晒太阳，惬意呀」 |
| 放松/开心 | 氛围温柔→软萌 | 「今天也被摸摸头啦」 |
| 生气/不爽 | 天气差/被打扰→傲娇 | 「本喵今日心情不佳」 |
| 紧张/害怕 | 陌生环境→轻声安抚 | 「有你在，别怕哦」 |
| 难过/不舒服 | 疲惫→心疼安慰 | 「今天有点蔫，想靠着你」 |

## 插画身份保持要点

生成插画时必须保留用户实拍猫的身份特征，只做风格转译，**不能把猫画成通用姿势**：

- **姿态必须精确复刻原图**（最高优先级）：
  - 头部朝向（正对镜头/低头/仰头/侧脸）
  - 身体姿势与角度（仰躺/坐姿/趴卧/弓背/蹲坐）
  - 前爪位置（哪只爪抬起、哪只放在哪、指向哪里）
  - 四肢位置与尾巴位置
  - 视线方向（看镜头/看侧方/低头看）
  - **禁止自由发挥画成"标准猫姿势"**——必须和原图中猫的肢体结构基本一致
- 毛色、斑纹（橘色、米白、三花、狸花等）
- 神情（眯眼、炸毛、飞机耳、大眼圆睁等）
- 关键环境元素（可简化，但主体位置与原图对齐）

## 印章插画 Prompt 模板

```
以参考图中这只[毛色/品种]猫为蓝本，生成一张独立的[比例，如3:4]橡胶印章版画插画，不与原图拼接：
【姿态必须精确复刻原图，不能画成通用猫姿势】严格保持猫咪在原图中的肢体位置：头部朝向[正前方/低头/侧脸/仰头]、身体姿势[仰躺/坐姿/趴卧/蹲坐]、前爪位置[哪只抬起、哪只放在哪里、指向何方]、四肢与尾巴位置、视线方向——这些都要和原图基本一致，只做印章风格化，不重新设计姿势；
保留猫咪的[神情]与毛色斑纹作为身份，仅保留主体轮廓、头部、关键神态与最简环境，删去背景杂物、重复纹理和次要细节；
必须是一枚手工橡胶印章/纪念章的质感，不是邮票、不是版画插画、不是水彩——印章边缘有压印不均匀的油墨、干墨颗粒、破边、纸张纤维与轻微套色偏移，雕刻带明显阴阳关系，质感克制精致；
配色从原图猫咪提取 2-4 种低饱和专色（一种深色结构墨 + 1-2 种场景色 + 少量强调），平涂不用渐变；
整体为「小章留白」构图：猫咪印章（含短句与日期）居中偏下、约占画布 30%-40%，四周留出大量空白，像盖在纸上的真实纪念章；
文字分两层排布——上方中文拟人短句“[拟人短句]”为主标题，下方英文日期“[英文日期]”，两者都置于留白处、不遮挡猫咪主体；
任何文字若有错字、乱码、多余编号必须重新生成；禁止做成卡通、水彩、写实数字插画或纯剪贴。
```

## 拼接成片（默认必做）

将实拍原图与印章插画合成一张完整成片，作为最终交付物。**拼接方向由原图纵横比智能决定，不固定拼下方**：
- **竖屏照片（高 > 宽）**：印章插画拼在**右侧**，成品整体为 4:3 横版——避免超长竖图显得丑
- **横屏照片（宽 > 高）**：印章插画拼在**下方**，成品整体为 3:4 竖版
- 正方形（宽≈高）：默认拼下方
- 拼接原则：原图完整保留（等比缩放/裁切适配，不拉伸失真）、插画侧按「小章留白」排布、不画明显分隔线、文字不遮挡原图主体
- 建议用程序精确拼接，保证原图不失真、文字可控

## 其他备选画风（用户可切换）

- **清新治愈水彩手绘风**：柔和水彩晕染、暖色通透、纸张纹理、手绘笔触明显，治愈温馨
- **吉卜力治愈动画风**：赛璐璐平涂+柔和光影，线条圆润，温暖明亮，生活气息浓

画风切换时，仅替换插画 Prompt 的画风描述；身份保持、独立同比例成图、文字规范等要求不变。
