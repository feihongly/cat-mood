# 插画与成片制作参考

## 产品输出约定：分步交付，不拼图

用户上传猫图后，**按三步分步交付**，插画不与原图拼接成长图：

1. **分析情绪 + 拟人文案**（见 `emotion-guide.md`，输出文字判断）
2. **单独生成一张印章风插画**（与原图**同比例**，独立成图）
3. 交付拟人文案 + 独立插画（两样分开呈现）

> 默认不制作「上实拍、下插画」拼接长图。仅当用户明确要求拼接成片时才合成（见文末「拼接成片（可选）」）。

## 默认画风：橡胶印章 / 复古版画风

- 黑白手工印章 / 复古版画质感
- 边缘压印不均、油墨轻微渗化、纸张纤维可见
- 做旧纪念章、邮戳、版画元素点缀
- 整体克制精致，有复古旅行纪念感

### 可选配色：低饱和淡彩（默认倾向）

- 基础为黑白，可选用**低饱和淡彩**（约 8–16 色）：米白、浅橙、浅棕、浅灰绿、淡蓝等克制配色
- 配色须低饱和、不刺眼，保持复古做旧质感

### 比例与构图
- **插画比例 = 用户上传原图的比例**（先实测原图宽高比，再按同比例生成）
- 画面撑满整个画布
- 文字少量、清晰，避免乱码

### 文字规范（关键）
- **主标题：中文拟人短句**，20 字以内，来自情绪拟人文案（见 `emotion-guide.md` 口吻）
- **日期：英文欧式风格**，如 `OCT 19, 2026`（如需精确时间可加时分），比中文日期更洋气
- 文字要清晰可读；**严禁**出现多余乱码字、重复短句、残留邮戳编号（如底部莫名数字/模糊字）
- 生成后必须核验画面文字，出现乱码需重新生成或清理

### 拟人短句风格库（agent 根据情绪与氛围自行选择）
| 情绪 | 氛围倾向 | 文案示例 |
|---|---|---|
| 放松/开心 | 天气好→慵懒治愈 | 「趴着晒太阳，惬意呀」 |
| 放松/开心 | 氛围温柔→软萌 | 「今天也被摸摸头啦」 |
| 生气/不爽 | 天气差/被打扰→傲娇 | 「本喵今日心情不佳」 |
| 紧张/害怕 | 陌生环境→轻声安抚 | 「有你在，别怕哦」 |
| 难过/不舒服 | 疲惫→心疼安慰 | 「今天有点蔫，想靠着你」 |

## 插画身份保持要点

生成插画时必须保留用户实拍猫的身份特征，只做风格转译：
- 毛色、斑纹（橘色、米白、三花、狸花等）
- 姿态（趴卧、摊开、弓背、躲避等）
- 神情（眯眼、炸毛、飞机耳等）
- 关键环境元素（可简化，但主体一致）

## 印章插画 Prompt 模板

```
以参考图中这只[毛色/品种]猫为蓝本，生成一张独立的[比例，如3:4]竖幅橡胶印章版画插画，不与原图拼接：
保留猫咪[姿态]和[神情]，用黑白手工印章/复古版画的方式呈现，
边缘有压印不均、油墨渗化、纸张纤维质感，
配中文拟人短句“[拟人短句]”作为主标题和英文日期“[英文日期]”，
文字清晰不多余不乱码，画面撑满整个画布。
```

## 拼接成片（可选，仅在用户明确要求时）

将实拍照片（上）与插画（下）合成一张成片：
- 按用户原图比例，上实拍完整 + 下插画同比例撑满
- 不画明显分隔线
- 建议用程序精确拼接，保证原图不失真、文字可控

## 其他备选画风（用户可切换）

- **清新治愈水彩手绘风**：柔和水彩晕染、暖色通透、纸张纹理、手绘笔触明显，治愈温馨
- **吉卜力治愈动画风**：赛璐璐平涂+柔和光影，线条圆润，温暖明亮，生活气息浓

画风切换时，仅替换插画 Prompt 的画风描述；身份保持、独立同比例成图、文字规范等要求不变。
