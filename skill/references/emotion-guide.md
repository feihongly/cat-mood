# 情绪判断参考

综合猫的肢体语言信号判断情绪。**只看单个信号易误判，必须综合多个信号。** 信号之间存在矛盾时，以更强烈、更明确的信号为准，并在输出中如实标注不确定性。

## 四档情绪总览

| 档位 | 典型状态 | 关键信号组合 |
|---|---|---|
| 1 放松 / 开心 | 熟悉环境里的松弛 | 身体舒展/摊成猫饼、尾巴自然或轻摆、瞳孔正常或微缩、慢眨眼、呼噜、耳朵朝前放松 |
| 2 紧张 / 害怕 | 感到威胁或陌生 | 身体压低贴地、炸毛、耳朵后压/飞机耳、瞳孔放大、夹尾巴、躲藏、发抖、嘶嘶声 |
| 3 生气 / 不爽 | 领地受侵或被打扰 | 耳朵紧贴后压、尾巴快速甩动/拍地、背毛竖起、低吼/哈气、瞳孔紧缩、身体僵硬弓起 |
| 4 难过 / 不舒服 | 身体或情绪不适 | 食欲下降、精神萎靡嗜睡、叫声异常（持续哀嚎/呜咽）、躲避、舔舐某处过度、排泄异常 |

## 分信号判断表

### 耳朵
- 朝前、自然放松 → 平静/好奇
- 向两侧微压（飞机耳）→ 警惕、紧张、害怕
- 紧贴头后 → 强烈害怕或生气

### 尾巴
- 自然下垂或轻摆 → 放松
- 竖直竖起且毛松开 → 紧张/防御
- 快速甩动或拍打地面 → 烦躁、生气
- 夹在两腿间 → 害怕、服从

### 眼睛
- 慢速眨眼（眼睛眯起又睁开）→ 信任、放松
- 瞳孔放大 → 紧张、害怕、兴奋（需结合环境）
- 瞳孔缩成细线 → 生气、攻击前兆
- 直勾勾盯视且身体僵硬 → 警惕/攻击

### 身体姿态
- 摊开、露出肚皮（放松环境）→ 放松信任
- 弓背、毛炸起 → 害怕或防御
- 压低贴地、匍匐 → 害怕、准备躲避
- 身体僵硬、静止不动 → 高度警惕

### 声音
- 呼噜 → 通常放松满意（也可能疼痛时的自我安抚，需结合其他信号）
- 短促喵叫 → 打招呼、需求
- 长声哀嚎/呜咽 → 不适、求助
- 嘶嘶/低吼 → 害怕或生气

### 行为
- 蹭人、踩奶 → 放松、亲昵
- 躲藏、不肯出来 → 害怕、不适
- 过度舔毛/攻击玩具 → 压力、焦虑
- 拒食、嗜睡、排泄异常 → 身体不适，建议就医

## 品种差异与信号降权

- **扁脸猫（如英短、波斯）**：瞳孔和表情难以观察，眼睛信号降权，优先看耳朵、尾巴、声音。
- **无尾/短尾猫（如曼基康、马恩岛）**：尾巴信号不可用，用身体姿态、耳朵、声音替代。
- **长毛猫**：姿态和背毛可能被遮挡，结合声音与行为判断。
- **幼猫/老年猫**：行为基线不同，需结合年龄。

## 不确定性处理

- 判断依据不充分时，如实说明，例如：「整体像放松，但耳朵有点后压，可能有点警惕，可以结合它今天的经历判断」。
- 把不确定性变成萌点和体贴，而不是武断结论。例：「我还不完全确定哦，但它这样趴着，大概率是舒服的，你再看看它耳朵有没有一直压着。」

## 健康与就医提醒（最高优先级）

出现以下信号时，**先提醒就医**，不做拟人化掩盖：
- 呼吸急促或困难、持续哀嚎、呕吐、腹泻、明显外伤出血、抽搐、无法站立
- 长时间拒食拒水、精神极度萎靡
- 任何让主人担心是疾病的异常

此时拟人文案可暂缓，优先给出「建议尽快就医」的明确提示和观察要点。
