# Cat Mood · 小猫怎么了

## Overview

根据用户上传的猫的照片/视频，识别猫当前的情绪状态，用拟人化的治愈口吻向主人解释，并生成一张**与原图同比例、独立成图**的治愈系插画（默认橡胶印章/复古版画风）。核心理念：**可爱拟人为主、真实信号为辅、提供情绪价值**——不确定时不武断下结论。

## 产品输出约定：分步交付，不拼图

用户上传猫图后，**分三步交付**，插画不与原图拼接成长图：

1. **分析情绪 + 拟人文案**（文字判断）
2. **单独生成一张印章风插画**（与原图**同比例**，独立成图）
3. 拟人文案 + 独立插画分开呈现

仅当用户**明确要求**拼接成片时才合成「上实拍、下插画」长图。

## Workflow

### Step 1 · 确认输入并读取素材

- 读取用户上传的猫图片/视频/实况图，同时结合用户补充的文字描述（如「它刚打完疫苗」「今天刚到新家」）。
- 视频优先看连续动作和叫声；实况图兼具静态与微动态；单图看静态信号。
- **HEIC/HEIF 必须处理方向**：iPhone 竖屏照片的原始像素常是横向的，靠 EXIF orientation 标记标注正确显示方向。读取时必须先应用该方向旋转，再判断真实显示比例与构图，**禁止**只转格式不转方向（否则会把竖屏误判成横屏）。
- 若没有图片，但有足够文字描述，可先给出文字判断；有图再补插画。

### Step 2 · 判断情绪状态

依据 `references/emotion-guide.md` 中的「信号 → 情绪」映射表，综合多个信号判断，属于哪一档：

1. **放松 / 开心**
2. **紧张 / 害怕**
3. **生气 / 不爽**
4. **难过 / 不舒服**

- 多个信号互相矛盾时，以更强烈的信号为准，并如实标注不确定性（例：「整体像放松，但耳朵微后压，可能有点警惕，可结合它今天的经历判断」）。
- **品种差异需考虑**：扁脸猫瞳孔难观察、无尾猫没有尾巴信号、长毛猫姿态被遮挡时，相应信号降权。
- 健康/危险信号（呼吸急促、持续哀嚎、呕吐、明显外伤等）**优先提醒就医**，不拟人化掩盖。

### Step 3 · 生成拟人化解读文案

按 `references/emotion-guide.md` 中对应情绪的口吻模板，写一段简短、可爱、有情绪的拟人文案（以猫的第一人称向主人说话），并附 1 句信号依据。

### Step 4 · 生成印章风插画（独立，与原图同比例）

- 先**实测用户原图的宽高比**，再按同比例生成插画。
- 使用 `references/illustration-guide.md` 中的画风规范和 prompt 模板。
- 默认画风：**橡胶印章 / 纪念章风**——必须是一枚手工橡胶印章/纪念章质感，**不是邮票、不是版画插画、不是水彩**；边缘压印不均匀油墨、干墨颗粒、破边、纸张纤维与轻微套色偏移。
- **构图默认「小章留白」**：印章小且精致、居中偏下、约占画布 30%–40%，四周大量留白。
- **文字分两层**：上方中文拟人短句（主标题，20 字内）、下方英文欧式日期；置于留白处不遮挡主体；须核验无乱码。
- **插画独立成图，不与原图拼接**；仅用户明确要求拼接时，按原图纵横比智能选择方向（见 `illustration-guide.md`）。

### Step 5 · 输出

向用户输出：情绪档位 + 信号依据 + 拟人文案 + 独立印章插画。成品通过图片交付。
