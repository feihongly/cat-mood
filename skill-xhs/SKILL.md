# Cat Mood · 小猫怎么了（小红书版）

## Overview

根据用户上传的猫照片/视频，识别情绪状态，用拟人化治愈口吻向主人解释，并生成一张与原图同比例、独立成图的橡胶印章插画。核心理念：**可爱拟人为主、真实信号为辅、提供情绪价值**——不确定时不武断下结论。

> 本版为小红书 Red Skill 适配版，将情绪判断与插画规范内联为单文件，便于上传与在支持生图的 AI 中执行。

## 输出约定：分步交付，不拼图

1. **分析情绪 + 拟人文案**（文字判断）
2. **单独生成一张印章风插画**（与原图同比例，独立成图）
3. 拟人文案 + 独立插画分开呈现

仅当用户明确要求拼接成片时才合成「上实拍、下插画」长图。

## Workflow

### Step 1 · 确认输入并读取素材
- 读取用户上传的猫图片/视频/实况图，结合补充文字描述（如「刚打完疫苗」「今天刚到新家」）。
- 视频优先看连续动作和叫声；实况图兼具静态与微动态；单图看静态信号。
- **HEIC/HEIF 必须处理方向**：iPhone 竖屏照片原始像素常为横向，靠 EXIF orientation 标记标注正确方向。读取时必须先应用该方向旋转，再判断真实比例与构图，禁止只转格式不转方向（否则竖屏会被误判为横屏）。

### Step 2 · 判断情绪状态
综合多个信号，判断属于哪一档。**只看单个信号易误判，必须综合多个信号。** 信号矛盾时以更强烈信号为准，并如实标注不确定性。

| 档位 | 典型状态 | 关键信号组合 |
|---|---|---|
| 1 放松 / 开心 | 熟悉环境里的松弛 | 身体舒展/摊成猫饼、尾巴自然或轻摆、瞳孔正常或微缩、慢眨眼、呼噜、耳朵朝前放松 |
| 2 紧张 / 害怕 | 感到威胁或陌生 | 身体压低贴地、炸毛、耳朵后压/飞机耳、瞳孔放大、夹尾巴、躲藏、发抖、嘶嘶声 |
| 3 生气 / 不爽 | 领地受侵或被打扰 | 耳朵紧贴后压、尾巴快速甩动/拍地、背毛竖起、低吼/哈气、瞳孔紧缩、身体僵硬弓起 |
| 4 难过 / 不舒服 | 身体或情绪不适 | 食欲下降、精神萎靡嗜睡、叫声异常、躲避、过度舔舐某处、排泄异常 |

**分信号要点：**
- **耳朵**：朝前放松→平静/好奇；飞机耳→警惕紧张；紧贴头后→强烈害怕或生气
- **尾巴**：自然下垂或轻摆→放松；竖直竖起毛松开→紧张防御；快速甩动拍地→烦躁生气；夹腿间→害怕
- **眼睛**：慢速眨眼→信任放松；瞳孔放大→紧张害怕或兴奋；瞳孔细线→生气攻击前兆；直勾盯视身体僵硬→警惕
- **身体**：摊开露肚皮→放松信任；弓背炸毛→害怕防御；压低贴地→害怕；僵硬静止→高度警惕
- **声音**：呼噜→通常放松（也可能疼痛自我安抚）；短促喵叫→打招呼需求；长声哀嚎→不适求助；嘶嘶低吼→害怕或生气
- **行为**：蹭人踩奶→放松亲昵；躲藏→害怕不适；过度舔毛/攻击玩具→压力焦虑；拒食嗜睡排泄异常→身体不适建议就医

**品种差异：** 扁脸猫瞳孔难观察（降权，优先耳朵/尾巴/声音）；无尾猫无尾巴信号；长毛猫姿态被遮挡结合声音行为。

**健康/危险信号（最高优先级，先提醒就医）：** 呼吸急促或困难、持续哀嚎、呕吐、腹泻、明显外伤出血、抽搐、无法站立、长时间拒食拒水、精神极度萎靡。出现时不做拟人化掩盖，优先提示就医和观察要点。

### Step 3 · 生成拟人化解读文案
以猫的第一人称向主人说话，简短可爱有情绪，附 1 句信号依据。用下方拟人短句风格库按情绪与氛围选择主标题。

| 情绪 | 氛围倾向 | 文案示例 |
|---|---|---|
| 放松/开心 | 天气好→慵懒治愈 | 「趴着晒太阳，惬意呀」 |
| 放松/开心 | 氛围温柔→软萌 | 「今天也被摸摸头啦」 |
| 生气/不爽 | 天气差/被打扰→傲娇 | 「本喵今日心情不佳」 |
| 紧张/害怕 | 陌生环境→轻声安抚 | 「有你在，别怕哦」 |
| 难过/不舒服 | 疲惫→心疼安慰 | 「今天有点蔫，想靠着你」 |

### Step 4 · 生成印章风插画（独立，与原图同比例）
1. 先**实测用户原图的宽高比**，再按同比例生成。
2. 用生图能力（如豆包 image_edit），以用户实拍猫为身份蓝本生成独立插画，不拼接。
3. **默认画风：橡胶印章 / 复古版画风**——黑白手工印章，边缘压印不均、油墨渗化、纸张纤维，做旧纪念章/邮戳点缀，克制精致。
4. **配色（默认倾向）：低饱和淡彩**——约 8–16 色（米白、浅橙、浅棕、浅灰绿、淡蓝等），低饱和不刺眼，保持复古做旧质感。
5. **比例与构图**：插画比例 = 原图比例，画面撑满整个画布。
6. **文字规范（关键）**：
   - 主标题：中文拟人短句，20 字内，来自拟人文案风格库
   - 日期：英文欧式风格，如 `OCT 19, 2026`（可加时分更精确），比中文洋气
   - 文字清晰可读，严禁多余乱码字、重复短句、残留邮戳编号；生成后必须核验画面文字，乱码需重新生成或清理
7. **身份保持**：保留猫的毛色/斑纹、姿态、神情等身份特征，只做风格转译。

**印章插画 Prompt 模板：**
```
以参考图中这只[毛色/品种]猫为蓝本，生成一张独立的[比例，如3:4]橡胶印章版画插画，不与原图拼接：
保留猫咪[姿态]和[神情]，用黑白手工印章/复古版画的方式呈现，
边缘有压印不均、油墨渗化、纸张纤维质感，
采用低饱和淡彩（约8-16色，米白、浅橙、浅棕、浅灰绿、淡蓝等克制配色），
配中文拟人短句“[拟人短句]”作为主标题和英文日期“[英文日期]”，
文字清晰不多余不乱码，画面撑满整个画布。
```

### Step 5 · 输出
向用户输出：情绪档位 + 信号依据 + 拟人文案 + 独立印章插画。成品通过图片交付。

## 备选画风（用户可切换）
- **清新治愈水彩手绘风**：柔和水彩晕染、暖色通透、纸张纹理、手绘笔触明显，治愈温馨
- **吉卜力治愈动画风**：赛璐璐平涂+柔和光影，线条圆润，温暖明亮，生活气息浓

画风切换时仅替换插画 Prompt 的画风描述；身份保持、独立同比例成图、文字规范不变。
